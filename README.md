# 📊 Аналіз клієнтів на ринку США по категоріях товарів

Повний аналіз даних роздрібних замовлень: від завантаження та очищення даних до SQL-аналітики та візуалізації.

## 📁 Структура репозиторію

| Файл | Опис |
|------|------|
| `Orders_Data_Analysis.ipynb` | Ноутбук (Google Colab): завантаження, очищення, обробка даних і візуалізація |
| `Проект` | SQL-запити для аналізу бази `retail.db` |

## 🗂 Датасет

[Retail Orders (Kaggle)](https://www.kaggle.com/datasets/ankitbansal06/retail-orders) — файл `orders.csv`.

## 🔄 Етапи проєкту

### 1. Завантаження даних
- Завантаження датасету з Kaggle через `kagglehub` та Kaggle API (`kaggle.json`)
- Розпакування `orders.csv.zip` і читання у `pandas`

### 2. Очищення та підготовка даних
- Перевірка пропусків (`df.isna().sum()`) та аналіз значень (`Ship Mode`)
- Приведення назв колонок до нижнього регістру та заміна пробілів на `_`
- Перетворення `order date` у формат `datetime`

### 3. Створення нових показників
- **discount** = `list_price × discount_percent × 0.01`
- **sale_price** = `list_price − discount`
- **profit** = `sale_price − cost_price`
- Видалення допоміжних колонок: `list_price`, `cost_price`, `discount_percent`

### 4. Збереження в SQLite
Очищені дані записуються в базу `retail.db` (таблиця `orders`).

### 5. Візуалізація (`matplotlib`, `seaborn`)
- Розподіл категорій і підкатегорій товарів
- Прибуток за категоріями
- Зв'язок між ціною продажу та прибутком
- Прибуток категорії *Technology* у США за тиждень (01–07.01.2023)
- Кореляційна матриця (heatmap) числових показників

### 6. SQL-аналітика
У файлі `queries.sql` реалізовано запити, що відповідають на питання:
1. Топ-10 товарів, які генерують найбільший дохід
2. Топ-5 найпопулярніших товарів у кожному регіоні (`ROW_NUMBER() OVER PARTITION BY`)
3. Порівняння продажів по місяцях: 2022 vs 2023
4. Місяць з найвищими продажами для кожної категорії (`RANK()`)
5. Підкатегорія з найбільшим зростанням у 2023 порівняно з 2022

## 🛠 Технології

- Python: `pandas`, `matplotlib`, `seaborn`, `sqlite3`
- SQL (SQLite): CTE, віконні функції, `CASE WHEN`, `strftime`
- Google Colab, Kaggle API

## ▶️ Як запустити

1. Відкрийте `Orders_Data_Analysis.ipynb` у Google Colab.
2. Отримайте `kaggle.json` у налаштуваннях акаунта Kaggle (*Settings → API → Create New Token*) і завантажте його, коли ноутбук попросить.
3. Виконайте всі комірки по черзі — буде створено `retail.db`.
4. Виконайте SQL-запити з файлу `Проект` у будь-якому SQLite-клієнті (наприклад, DB Browser for SQLite).
